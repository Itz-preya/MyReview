# 🌟 MyReview – Static Website

**MyReview** is a multi-page static website built purely using **HTML, CSS, and JavaScript**. It showcases themed pages such as *Café*, *Hotel*, *Hospital*, *Restaurant*, and *Gallery*, each with unique layouts and visuals.  
This project is ideal for learning or demonstrating front-end design fundamentals without requiring a backend or complex setup.

---

## 🚀 Features

- 🌐 **Multi-Page Design:** Each category (Café, Hotel, Hospital, etc.) has its own dedicated page.  
- 💻 **Pure Frontend Stack:** Built entirely with HTML, CSS, and JavaScript — no frameworks or dependencies.  
- ⚡ **Instant Preview:** Simply open files in a browser or use VS Code’s Live Server to view locally.  
- 🎨 **Custom Themes:** Each page includes customized colors, images, and typography for visual variety.  
- 🧭 **Easy Navigation:** Can be extended with menus or buttons for smooth browsing across sections.

## 🧩 Getting Started

### Option 1 — Open Directly
1. Locate any `.html` file (e.g., `REVIEW.HTML`, `final.html`, or `homegalary.html`).
2. Double-click the file to open it in your preferred web browser.

### Option 2 — Use Live Server (Recommended)
1. Open the project folder (`HW1`) in **Visual Studio Code**.
2. Install the **Live Server** extension (if not already installed).
3. Right-click any entry page (e.g., `REVIEW.HTML`) and choose **“Open with Live Server”**.
4. Your site will automatically open in a browser and refresh on every save.

## 💡 Tips & Best Practices

- ✅ **Normalize filenames:** Rename `REVIEW.HTML` → `review.html` and `2.JS` → `2.js` for consistency.  
- 🔗 **Add Navigation Menus:** Link all pages using a common header or footer.  
- 🧹 **Organize Assets:** Move stylesheets and scripts into `/css` and `/js` subfolders for better structure.  
- 📱 **Make It Responsive:** Add media queries for mobile and tablet support.  
- 🪄 **Enhance Interactivity:** Use JavaScript for small dynamic effects (like image sliders or form validation).
